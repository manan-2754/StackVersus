## Detailed Breakdown

### Shadcn UI

_Copy-paste components built on Radix and Tailwind_

**Pros:**

- You own the component code
- Accessible Radix primitives
- Tailwind styling

**Cons:**

- You maintain updates yourself
- Assumes Tailwind

---

### Radix UI

_Unstyled, accessible UI primitives_

**Pros:**

- Accessible primitives
- Unstyled and composable
- Foundation of shadcn/ui

**Cons:**

- You style everything
- Slower development pace recently

## Key Differences

- **Positioning:** Shadcn UI — copy-paste components built on Radix and Tailwind. Radix UI — unstyled, accessible UI primitives.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Pricing:** Shadcn UI — free and open source. Radix UI — free and open source.
- **Signature strength:** Shadcn UI — you own the component code. Radix UI — accessible primitives.
