## Detailed Breakdown

### Redpanda

_Kafka-compatible streaming platform written in C++_

**Pros:**

- Kafka API compatible
- No JVM or ZooKeeper
- Low latency

**Cons:**

- BSL license for the core
- Smaller community

---

### Apache Pulsar

_Cloud-native distributed messaging and streaming_

**Pros:**

- Built-in multi-tenancy
- Tiered storage
- Queue and stream semantics

**Cons:**

- Complex architecture
- Smaller community than Kafka

---

## Key Differences

- **Positioning:** Redpanda — Kafka-compatible streaming platform written in C++. Apache Pulsar — cloud-native distributed messaging and streaming.
- Licensing differs: Redpanda is source-available while Apache Pulsar is open source.
- **Pricing:** Redpanda — free community edition; paid cloud and enterprise. Apache Pulsar — free and open source.
- **Signature strength:** Redpanda — Kafka API compatible. Apache Pulsar — built-in multi-tenancy.
