## Detailed Breakdown

### PostHog

_Open-source product analytics suite_

**Pros:**

- Analytics, session replay, feature flags and experiments
- Generous free usage tier
- Open source

**Cons:**

- Breadth means some tools are less deep
- Self-hosting is only supported at small scale

---

### Heap

_Product analytics with automatic event capture_

**Pros:**

- Autocapture of user interactions
- Retroactive event definitions
- Session replay available

**Cons:**

- Autocapture can produce noisy data
- Pricing is not transparent

## Key Differences

- **Positioning:** PostHog — open-source product analytics suite. Heap — product analytics with automatic event capture.
- Licensing differs: PostHog is open source while Heap is proprietary.
- **Deployment:** PostHog — self-hosted or managed cloud. Heap — managed cloud.
- **Pricing:** PostHog — free tier, then usage-based pricing. Heap — free tier with paid plans.
- **Signature strength:** PostHog — analytics, session replay, feature flags and experiments. Heap — autocapture of user interactions.
