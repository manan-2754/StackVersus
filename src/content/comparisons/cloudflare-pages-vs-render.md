## Detailed Breakdown

### Cloudflare Pages

_Static and full-stack hosting on Cloudflare’s network_

**Pros:**

- Generous free tier with unlimited static bandwidth
- Integrates with Workers, R2 and D1
- Fast global network

**Cons:**

- Workers runtime is not full Node.js
- Cloudflare is steering new projects toward Workers

---

### Render

_Unified cloud for apps, databases and cron jobs_

**Pros:**

- Heroku-like simplicity
- Managed Postgres and key-value stores
- Background workers and cron jobs

**Cons:**

- Free instances spin down when idle
- Fewer regions than hyperscalers

---

## Key Differences

- **Positioning:** Cloudflare Pages — static and full-stack hosting on Cloudflare’s network. Render — unified cloud for apps, databases and cron jobs.
- Both share the same licensing model (proprietary), so the decision comes down to features and workflow fit.
- **Pricing:** Cloudflare Pages — free tier with paid plans. Render — free tier with paid plans.
- **Signature strength:** Cloudflare Pages — generous free tier with unlimited static bandwidth. Render — Heroku-like simplicity.
