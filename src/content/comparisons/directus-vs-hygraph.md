## Detailed Breakdown

### Directus

_Data platform that adds an API and admin app to any SQL database_

**Pros:**

- Works on top of existing SQL schemas
- Instant REST and GraphQL APIs
- No-code admin app

**Cons:**

- BSL license requires a paid license for larger organizations
- Admin customization has a learning curve

---

### Hygraph

_GraphQL-native headless CMS_

**Pros:**

- Native GraphQL API including mutations
- Content federation from external sources
- Strong schema modeling

**Cons:**

- GraphQL-centric approach
- Lower-tier limits can be restrictive

---

## Key Differences

- **Positioning:** Directus — data platform that adds an API and admin app to any SQL database. Hygraph — GraphQL-native headless CMS.
- Licensing differs: Directus is source-available while Hygraph is proprietary.
- **Deployment:** Directus — self-hosted or managed cloud. Hygraph — managed cloud.
- **Pricing:** Directus — free open source; paid managed cloud. Hygraph — free tier with paid plans.
- **Signature strength:** Directus — works on top of existing SQL schemas. Hygraph — native GraphQL API including mutations.

## Frequently Asked Questions

### Is Directus better than Hygraph?

It depends on your requirements. Directus is a strong fit for teams that want a CMS on top of an existing SQL database, while Hygraph suits teams building GraphQL-first content APIs.

### Is Directus free to use?

Yes, you can start with Directus for free. Pricing model: Free open source; paid managed cloud.

### Is Hygraph free to use?

Yes, you can start with Hygraph for free. Pricing model: Free tier with paid plans.

### Can I self-host Directus or Hygraph?

Directus can be self-hosted. Deployment options: self-hosted or managed cloud. Hygraph is offered as a managed service: managed cloud.

### What are the main drawbacks of Directus and Hygraph?

Directus: BSL license requires a paid license for larger organizations; admin customization has a learning curve. Hygraph: GraphQL-centric approach; lower-tier limits can be restrictive.
