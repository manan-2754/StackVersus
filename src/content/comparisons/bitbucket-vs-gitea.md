- Jira integration
- Bitbucket Pipelines

**Cons:**

- Self-hosting requires Data Center

### Gitea

_Lightweight self-hosted Git service_

**Pros:**

- Very lightweight
- Actions-compatible CI
- Easy to run

**Cons:**

- Smaller ecosystem
- You manage hosting

## Key Differences

- **Positioning:** Bitbucket — git hosting by Atlassian. Gitea — lightweight self-hosted Git service.
- Licensing differs: Bitbucket is proprietary while Gitea is open source.
- **Deployment:** Bitbucket — self-hosted or managed cloud. Gitea — self-hosted.
- **Pricing:** Bitbucket — free tier with paid plans. Gitea — free and open source.
- **Signature strength:** Bitbucket — Jira integration. Gitea — very lightweight.
