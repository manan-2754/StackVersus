## Detailed Breakdown

### SvelteKit

_Full-stack framework for Svelte_

**Pros:**

- Compiled output with small bundles
- Simple, readable component syntax
- Adapters for many hosts

**Cons:**

- Smaller ecosystem than React
- Smaller hiring pool

---

### Gatsby

_React static site generator with a GraphQL data layer_

**Pros:**

- Large plugin library
- GraphQL layer unifies data sources
- Strong image handling

**Cons:**

- Development has slowed significantly
- Build times grow with site size

---

## Key Differences

- **Positioning:** SvelteKit — full-stack framework for Svelte. Gatsby — React static site generator with a GraphQL data layer.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Pricing:** SvelteKit — free and open source. Gatsby — free and open source.
- **Signature strength:** SvelteKit — compiled output with small bundles. Gatsby — large plugin library.
