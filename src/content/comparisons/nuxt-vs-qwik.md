## Detailed Breakdown

### Nuxt

_Full-stack framework for Vue_

**Pros:**

- File-based routing and auto-imports
- Nitro server engine deploys almost anywhere
- Rich module ecosystem

**Cons:**

- Tied to Vue
- Major upgrades require migration work

---

### Qwik

_Resumable framework for instant-loading web apps_

**Pros:**

- Resumability avoids hydration cost
- Fine-grained lazy loading
- Familiar JSX syntax

**Cons:**

- Small ecosystem
- New mental model to learn

---

## Key Differences

- **Positioning:** Nuxt — full-stack framework for Vue. Qwik — resumable framework for instant-loading web apps.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Pricing:** Nuxt — free and open source. Qwik — free and open source.
- **Signature strength:** Nuxt — file-based routing and auto-imports. Qwik — resumability avoids hydration cost.
