## Detailed Breakdown

### Supabase

_Open-source Postgres development platform_

**Pros:**

- Full Postgres database
- Auth, storage, edge functions and realtime
- Self-hostable

**Cons:**

- Self-hosting is more involved than the cloud
- Free projects pause after inactivity

---

### Appwrite

_Open-source backend platform for web and mobile_

**Pros:**

- Self-host with Docker
- Auth, databases, storage and functions
- Many client SDKs

**Cons:**

- Smaller community than Firebase
- Cloud offering is younger

---

## Key Differences

- **Positioning:** Supabase — open-source Postgres development platform. Appwrite — open-source backend platform for web and mobile.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Pricing:** Supabase — free open source; paid managed cloud. Appwrite — free open source; paid managed cloud.
- **Signature strength:** Supabase — full Postgres database. Appwrite — self-host with Docker.
