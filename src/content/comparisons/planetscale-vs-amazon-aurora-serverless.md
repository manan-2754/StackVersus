## Detailed Breakdown

### PlanetScale

_Database platform built on Vitess, now offering Postgres too_

**Pros:**

- Vitess-powered horizontal scaling
- Non-blocking schema changes
- Database branching

**Cons:**

- Free Hobby tier was removed in 2024
- Premium pricing

---

### Amazon Aurora Serverless

_Auto-scaling MySQL and PostgreSQL on AWS_

**Pros:**

- Automatic capacity scaling
- MySQL and Postgres compatibility
- Deep AWS integration

**Cons:**

- AWS only
- Pricing can be complex to estimate

---

## Key Differences

- **Positioning:** PlanetScale — database platform built on Vitess, now offering Postgres too. Amazon Aurora Serverless — auto-scaling MySQL and PostgreSQL on AWS.
- Both share the same licensing model (proprietary), so the decision comes down to features and workflow fit.
- **Pricing:** PlanetScale — paid plans; free trial available. Amazon Aurora Serverless — pay-as-you-go usage pricing.
- **Signature strength:** PlanetScale — vitess-powered horizontal scaling. Amazon Aurora Serverless — automatic capacity scaling.

## Frequently Asked Questions

### Is PlanetScale better than Amazon Aurora Serverless?

It depends on your requirements. PlanetScale is a strong fit for high-scale MySQL workloads, while Amazon Aurora Serverless suits AWS workloads with variable traffic.

### Is PlanetScale free to use?

PlanetScale does not have a permanent free plan. Pricing model: Paid plans; free trial available.

### Is Amazon Aurora Serverless free to use?

Amazon Aurora Serverless does not have a permanent free plan. Pricing model: Pay-as-you-go usage pricing.

### Can I self-host PlanetScale or Amazon Aurora Serverless?

PlanetScale is offered as a managed service: managed cloud. Amazon Aurora Serverless is offered as a managed service: managed cloud.

### What are the main drawbacks of PlanetScale and Amazon Aurora Serverless?

PlanetScale: free Hobby tier was removed in 2024; premium pricing. Amazon Aurora Serverless: AWS only; pricing can be complex to estimate.
