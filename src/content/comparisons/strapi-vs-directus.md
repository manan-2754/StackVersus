## Detailed Breakdown

### Strapi

_Open-source Node.js headless CMS_

**Pros:**

- Admin panel with a visual content-type builder
- REST and GraphQL APIs
- Large plugin ecosystem

**Cons:**

- Major version upgrades can be painful
- Some features gated behind paid plans

---

### Directus

_Data platform that adds an API and admin app to any SQL database_

**Pros:**

- Works on top of existing SQL schemas
- Instant REST and GraphQL APIs
- No-code admin app

**Cons:**

- BSL license requires a paid license for larger organizations
- Admin customization has a learning curve

---

## Key Differences

- **Positioning:** Strapi — open-source Node.js headless CMS. Directus — data platform that adds an API and admin app to any SQL database.
- Licensing differs: Strapi is open source while Directus is source-available.
- **Pricing:** Strapi — free open source; paid managed cloud. Directus — free open source; paid managed cloud.
- **Signature strength:** Strapi — admin panel with a visual content-type builder. Directus — works on top of existing SQL schemas.
