## Frequently Asked Questions

### Is GitHub Advanced Security better than Checkmarx?

It depends on your requirements. GitHub Advanced Security is a strong fit for GitHub Enterprise customers, while Checkmarx suits large enterprises with compliance needs.

### Is GitHub Advanced Security free to use?

Yes, you can start with GitHub Advanced Security for free. Pricing model: Free for public repos; paid for private repos.

### Is Checkmarx free to use?

Checkmarx does not have a permanent free plan. Pricing model: Custom enterprise pricing.

### Can I self-host GitHub Advanced Security or Checkmarx?

GitHub Advanced Security is offered as a managed service: managed cloud. Checkmarx can be self-hosted. Deployment options: self-hosted or managed cloud.

### What are the main drawbacks of GitHub Advanced Security and Checkmarx?

GitHub Advanced Security: paid add-on for private repositories; GitHub only. Checkmarx: expensive; slower scans.
