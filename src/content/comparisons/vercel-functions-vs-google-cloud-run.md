## Detailed Breakdown

### Vercel Functions

_Serverless functions on Vercel_

**Pros:**

- Zero-config with Next.js
- Fluid compute improves concurrency
- Deployed alongside your frontend

**Cons:**

- Tied to Vercel
- Usage costs at scale

---

### Google Cloud Run

_Serverless containers and functions on Google Cloud_

**Pros:**

- Run any container image
- Scales to zero
- Supports both functions and services

**Cons:**

- Cold starts
- Google Cloud specific

## Key Differences

- **Positioning:** Vercel Functions — serverless functions on Vercel. Google Cloud Run — serverless containers and functions on Google Cloud.
- Both share the same licensing model (proprietary), so the decision comes down to features and workflow fit.
- **Pricing:** Vercel Functions — free tier, then usage-based pricing. Google Cloud Run — free tier, then usage-based pricing.
- **Signature strength:** Vercel Functions — zero-config with Next.js. Google Cloud Run — run any container image.
