## Detailed Breakdown

### Supabase

_Open-source Postgres development platform_

**Pros:**

- Full Postgres database
- Auth, storage, edge functions and realtime
- Self-hostable

**Cons:**

- Self-hosting is more involved than the cloud
- Free projects pause after inactivity

---

### Nhost

_Open-source backend with Postgres and GraphQL_

**Pros:**

- Postgres with a Hasura GraphQL API
- Auth and storage included
- Self-hostable

**Cons:**

- GraphQL-centric
- Smaller ecosystem

---

## Key Differences

- **Positioning:** Supabase — open-source Postgres development platform. Nhost — open-source backend with Postgres and GraphQL.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Pricing:** Supabase — free open source; paid managed cloud. Nhost — free open source; paid managed cloud.
- **Signature strength:** Supabase — full Postgres database. Nhost — Postgres with a Hasura GraphQL API.
