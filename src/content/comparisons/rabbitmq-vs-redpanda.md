## Detailed Breakdown

### RabbitMQ

_Widely deployed open-source message broker_

**Pros:**

- Flexible routing
- Multiple protocols
- Mature and well documented

**Cons:**

- Lower throughput than Kafka
- Clustering needs tuning

---

### Redpanda

_Kafka-compatible streaming platform written in C++_

**Pros:**

- Kafka API compatible
- No JVM or ZooKeeper
- Low latency

**Cons:**

- BSL license for the core
- Smaller community

---

## Key Differences

- **Positioning:** RabbitMQ — widely deployed open-source message broker. Redpanda — Kafka-compatible streaming platform written in C++.
- Licensing differs: RabbitMQ is open source while Redpanda is source-available.
- **Pricing:** RabbitMQ — free and open source. Redpanda — free community edition; paid cloud and enterprise.
- **Signature strength:** RabbitMQ — flexible routing. Redpanda — Kafka API compatible.
