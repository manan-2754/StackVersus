## Detailed Breakdown

### Chakra UI

_Accessible React component library_

**Pros:**

- Style props API
- Accessibility built in
- Theming

**Cons:**

- v3 migration effort
- Runtime styling cost

---

### Radix UI

_Unstyled, accessible UI primitives_

**Pros:**

- Accessible primitives
- Unstyled and composable
- Foundation of shadcn/ui

**Cons:**

- You style everything
- Slower development pace recently

---

## Key Differences

- **Positioning:** Chakra UI — accessible React component library. Radix UI — unstyled, accessible UI primitives.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Pricing:** Chakra UI — free and open source. Radix UI — free and open source.
- **Signature strength:** Chakra UI — style props API. Radix UI — accessible primitives.
