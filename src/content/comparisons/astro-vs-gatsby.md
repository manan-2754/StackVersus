## Detailed Breakdown

### Astro

_Content-focused web framework with islands architecture_

**Pros:**

- Ships zero JavaScript by default
- Mix React, Vue and Svelte components
- Excellent Markdown and content collections

**Cons:**

- Not ideal for highly interactive apps
- Smaller ecosystem than Next.js

---

### Gatsby

_React static site generator with a GraphQL data layer_

**Pros:**

- Large plugin library
- GraphQL layer unifies data sources
- Strong image handling

**Cons:**

- Development has slowed significantly
- Build times grow with site size

---

## Key Differences

- **Positioning:** Astro — content-focused web framework with islands architecture. Gatsby — React static site generator with a GraphQL data layer.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Pricing:** Astro — free and open source. Gatsby — free and open source.
- **Signature strength:** Astro — ships zero JavaScript by default. Gatsby — large plugin library.
