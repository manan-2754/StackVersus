## Detailed Breakdown

### TypeORM

_Decorator-based ORM for TypeScript and JavaScript_

**Pros:**

- Active Record and Data Mapper patterns
- Supports many databases
- Popular with NestJS

**Cons:**

- Weaker type safety than newer ORMs
- Uneven maintenance history

---

### Kysely

_Type-safe TypeScript SQL query builder_

**Pros:**

- Fully type-safe queries
- Lightweight with no runtime magic
- Works across SQL dialects

**Cons:**

- Not a full ORM
- Types must be kept in sync with your schema

---

## Key Differences

- **Positioning:** TypeORM — decorator-based ORM for TypeScript and JavaScript. Kysely — type-safe TypeScript SQL query builder.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Pricing:** TypeORM — free and open source. Kysely — free and open source.
- **Signature strength:** TypeORM — active Record and Data Mapper patterns. Kysely — fully type-safe queries.
