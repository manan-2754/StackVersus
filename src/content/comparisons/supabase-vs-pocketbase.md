## Detailed Breakdown

### Supabase

_Open-source Postgres development platform_

**Pros:**

- Full Postgres database
- Auth, storage, edge functions and realtime
- Self-hostable

**Cons:**

- Self-hosting is more involved than the cloud
- Free projects pause after inactivity

---

### PocketBase

_Open-source backend in a single executable_

**Pros:**

- Single binary with embedded SQLite
- Realtime subscriptions and auth
- Extremely easy to deploy

**Cons:**

- Not built for horizontal scaling
- Pre-1.0 releases may include breaking changes

---

## Key Differences

- **Positioning:** Supabase — open-source Postgres development platform. PocketBase — open-source backend in a single executable.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Deployment:** Supabase — self-hosted or managed cloud. PocketBase — self-hosted.
- **Pricing:** Supabase — free open source; paid managed cloud. PocketBase — free and open source.
- **Signature strength:** Supabase — full Postgres database. PocketBase — single binary with embedded SQLite.
