## Detailed Breakdown

### Jest

_Batteries-included JavaScript testing framework_

**Pros:**

- Zero configuration for many projects
- Snapshot testing and mocking built in
- Huge community

**Cons:**

- Slower than Vite-native runners
- ESM support still has rough edges

---

### Node.js Test Runner

_Test runner built into Node.js (node:test)_

**Pros:**

- Nothing extra to install
- Built-in mocking and coverage
- Stable since Node.js 20

**Cons:**

- Fewer features than Jest or Vitest
- Smaller ecosystem of reporters and plugins

---

## Key Differences

- **Positioning:** Jest — batteries-included JavaScript testing framework. Node.js Test Runner — test runner built into Node.js (node:test).
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Deployment:** Jest — library / framework in your stack. Node.js Test Runner — built into the Node.js runtime.
- **Pricing:** Jest — free and open source. Node.js Test Runner — free and open source.
- **Signature strength:** Jest — zero configuration for many projects. Node.js Test Runner — nothing extra to install.
