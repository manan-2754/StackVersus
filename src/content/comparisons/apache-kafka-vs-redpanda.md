## Detailed Breakdown

### Apache Kafka

_Distributed event streaming platform_

**Pros:**

- Massive throughput
- Durable, replayable log
- Huge connector ecosystem

**Cons:**

- Operational complexity
- Overkill for simple queues

---

### Redpanda

_Kafka-compatible streaming platform written in C++_

**Pros:**

- Kafka API compatible
- No JVM or ZooKeeper
- Low latency

**Cons:**

- BSL license for the core
- Smaller community

---

## Key Differences

- **Positioning:** Apache Kafka — distributed event streaming platform. Redpanda — Kafka-compatible streaming platform written in C++.
- Licensing differs: Apache Kafka is open source while Redpanda is source-available.
- **Deployment:** Apache Kafka — self-hosted or managed by many vendors. Redpanda — self-hosted or managed cloud.
- **Pricing:** Apache Kafka — free and open source. Redpanda — free community edition; paid cloud and enterprise.
- **Signature strength:** Apache Kafka — massive throughput. Redpanda — Kafka API compatible.
