# AWS Lambda vs Google Cloud Run: Head-to-Head Comparison

## Quick Verdict

> AWS Lambda is the better pick for event-driven workloads in the AWS ecosystem. Google Cloud Run is the better pick for containerized services that should scale to zero.

## Detailed Breakdown

### AWS Lambda

_Event-driven serverless compute on AWS_

**Pros:**

- Deep AWS event integrations
- Many supported runtimes
- Generous free tier

**Cons:**

- Cold starts
- Vendor lock-in

---

### Google Cloud Run

_Serverless containers and functions on Google Cloud_

**Pros:**

- Run any container image
- Scales to zero
- Supports both functions and services

**Cons:**

- Cold starts
- Google Cloud specific

---

## Key Differences

- **Positioning:** AWS Lambda — event-driven serverless compute on AWS. Google Cloud Run — serverless containers and functions on Google Cloud.
- Both share the same licensing model (proprietary), so the decision comes down to features and workflow fit.
- **Pricing:** AWS Lambda — free tier, then usage-based pricing. Google Cloud Run — free tier, then usage-based pricing.
- **Signature strength:** AWS Lambda — deep AWS event integrations. Google Cloud Run — run any container image.

## Frequently Asked Questions

### Is AWS Lambda better than Google Cloud Run?

It depends on your requirements. AWS Lambda is a strong fit for event-driven workloads in the AWS ecosystem, while Google Cloud Run suits containerized services that should scale to zero.

### Is AWS Lambda free to use?

Yes, you can start with AWS Lambda for free. Pricing model: Free tier, then usage-based pricing.

### Is Google Cloud Run free to use?

Yes, you can start with Google Cloud Run for free. Pricing model: Free tier, then usage-based pricing.

### Can I self-host AWS Lambda or Google Cloud Run?

AWS Lambda is offered as a managed service: managed cloud. Google Cloud Run is offered as a managed service: managed cloud.

### What are the main drawbacks of AWS Lambda and Google Cloud Run?

AWS Lambda: cold starts; vendor lock-in. Google Cloud Run: cold starts; Google Cloud specific.
