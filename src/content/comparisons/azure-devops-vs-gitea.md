## Key Differences

- **Positioning:** Azure DevOps — Microsoft suite for repos, pipelines and boards. Gitea — lightweight self-hosted Git service.
- Licensing differs: Azure DevOps is proprietary while Gitea is open source.
- **Deployment:** Azure DevOps — self-hosted or managed cloud. Gitea — self-hosted.
- **Pricing:** Azure DevOps — free tier with paid plans. Gitea — free and open source.
- **Signature strength:** Azure DevOps — boards, Repos, Pipelines and Artifacts. Gitea — very lightweight.
