## Detailed Breakdown

### Snowflake

_Cloud data platform with separated storage and compute_

**Pros:**

- Separation of storage and compute
- Runs on AWS, Azure and Google Cloud
- Secure data sharing marketplace

**Cons:**

- Credit consumption can surprise
- Proprietary platform

---

### Azure Synapse Analytics

_Analytics service on Azure combining SQL and Spark_

**Pros:**

- Integrated with the Azure ecosystem
- Serverless and dedicated SQL pools
- Built-in Spark

**Cons:**

- Microsoft is steering new workloads toward Microsoft Fabric
- Azure only

---

## Key Differences

- **Positioning:** Snowflake — cloud data platform with separated storage and compute. Azure Synapse Analytics — analytics service on Azure combining SQL and Spark.
- Both share the same licensing model (proprietary), so the decision comes down to features and workflow fit.
- **Pricing:** Snowflake — pay-as-you-go usage pricing. Azure Synapse Analytics — pay-as-you-go usage pricing.
- **Signature strength:** Snowflake — separation of storage and compute. Azure Synapse Analytics — integrated with the Azure ecosystem.
