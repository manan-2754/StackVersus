## Detailed Breakdown

### Foundation

_Responsive front-end framework by ZURB_

**Pros:**

- Flexible grid
- Email framework
- Accessibility focus

**Cons:**

- Development has slowed
- Smaller community

---

### UnoCSS

_Instant on-demand atomic CSS engine_

**Pros:**

- Extremely fast
- Preset-based customization
- Tailwind-compatible presets

**Cons:**

- Smaller ecosystem
- More configuration

## Key Differences

- **Positioning:** Foundation — responsive front-end framework by ZURB. UnoCSS — instant on-demand atomic CSS engine.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Pricing:** Foundation — free and open source. UnoCSS — free and open source.
- **Signature strength:** Foundation — flexible grid. UnoCSS — extremely fast.
