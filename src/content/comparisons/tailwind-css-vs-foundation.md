## Detailed Breakdown

### Tailwind CSS

_Utility-first CSS framework_

**Pros:**

- Rapid styling with utilities
- Small production CSS
- Excellent tooling

**Cons:**

- Verbose class lists
- Learning curve

---

### Foundation

_Responsive front-end framework by ZURB_

**Pros:**

- Flexible grid
- Email framework
- Accessibility focus

**Cons:**

- Development has slowed
- Smaller community

## Key Differences

- **Positioning:** Tailwind CSS — utility-first CSS framework. Foundation — responsive front-end framework by ZURB.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Pricing:** Tailwind CSS — free and open source. Foundation — free and open source.
- **Signature strength:** Tailwind CSS — rapid styling with utilities. Foundation — flexible grid.
