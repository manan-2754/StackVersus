## Detailed Breakdown

### Gatsby

_React static site generator with a GraphQL data layer_

**Pros:**

- Large plugin library
- GraphQL layer unifies data sources
- Strong image handling

**Cons:**

- Development has slowed significantly
- Build times grow with site size

---

### Qwik

_Resumable framework for instant-loading web apps_

**Pros:**

- Resumability avoids hydration cost
- Fine-grained lazy loading
- Familiar JSX syntax

**Cons:**

- Small ecosystem
- New mental model to learn

---

## Key Differences

- **Positioning:** Gatsby — React static site generator with a GraphQL data layer. Qwik — resumable framework for instant-loading web apps.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Pricing:** Gatsby — free and open source. Qwik — free and open source.
- **Signature strength:** Gatsby — large plugin library. Qwik — resumability avoids hydration cost.
