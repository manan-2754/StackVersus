## Detailed Breakdown

### Remix

_Web-standards-focused full-stack React framework_

**Pros:**

- Nested routes with loaders and actions
- Progressive enhancement
- Built on Web Fetch APIs

**Cons:**

- Merge into React Router v7 can confuse newcomers
- Smaller ecosystem than Next.js

---

### Gatsby

_React static site generator with a GraphQL data layer_

**Pros:**

- Large plugin library
- GraphQL layer unifies data sources
- Strong image handling

**Cons:**

- Development has slowed significantly
- Build times grow with site size

---

## Key Differences

- **Positioning:** Remix — web-standards-focused full-stack React framework. Gatsby — React static site generator with a GraphQL data layer.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Pricing:** Remix — free and open source. Gatsby — free and open source.
- **Signature strength:** Remix — nested routes with loaders and actions. Gatsby — large plugin library.
