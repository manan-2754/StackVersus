## Detailed Breakdown

### Appwrite

_Open-source backend platform for web and mobile_

**Pros:**

- Self-host with Docker
- Auth, databases, storage and functions
- Many client SDKs

**Cons:**

- Smaller community than Firebase
- Cloud offering is younger

---

### Nhost

_Open-source backend with Postgres and GraphQL_

**Pros:**

- Postgres with a Hasura GraphQL API
- Auth and storage included
- Self-hostable

**Cons:**

- GraphQL-centric
- Smaller ecosystem

---

## Key Differences

- **Positioning:** Appwrite — open-source backend platform for web and mobile. Nhost — open-source backend with Postgres and GraphQL.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Pricing:** Appwrite — free open source; paid managed cloud. Nhost — free open source; paid managed cloud.
- **Signature strength:** Appwrite — self-host with Docker. Nhost — Postgres with a Hasura GraphQL API.
