## Detailed Breakdown

### Pulumi

_Infrastructure as code in general-purpose languages_

**Pros:**

- Use real programming languages
- Strong testing and abstraction
- Can use Terraform providers via bridges

**Cons:**

- More freedom can mean less consistency
- Smaller community than Terraform

---

### OpenTofu

_Open-source Terraform fork under the Linux Foundation_

**Pros:**

- Drop-in Terraform compatibility
- MPL-licensed and community governed
- Adds features like state encryption

**Cons:**

- Gradual divergence from Terraform
- Smaller vendor support

---

## Key Differences

- **Positioning:** Pulumi — infrastructure as code in general-purpose languages. OpenTofu — open-source Terraform fork under the Linux Foundation.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Deployment:** Pulumi — CLI with optional Pulumi Cloud. OpenTofu — CLI.
- **Pricing:** Pulumi — free open-source CLI; paid Pulumi Cloud. OpenTofu — free and open source.
- **Signature strength:** Pulumi — use real programming languages. OpenTofu — drop-in Terraform compatibility.
