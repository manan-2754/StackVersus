# OpenTofu vs AWS CDK: Head-to-Head Comparison

## Quick Verdict

> OpenTofu is the better pick for teams wanting Terraform compatibility with an open-source license. AWS CDK is the better pick for AWS developers who want infrastructure in code.

## Detailed Breakdown

### OpenTofu

_Open-source Terraform fork under the Linux Foundation_

**Pros:**

- Drop-in Terraform compatibility
- MPL-licensed and community governed
- Adds features like state encryption

**Cons:**

- Gradual divergence from Terraform
- Smaller vendor support

---

### AWS CDK

_Define AWS infrastructure in TypeScript, Python and more_

**Pros:**

- High-level constructs
- Real programming languages
- Synthesizes to CloudFormation

**Cons:**

- AWS focused
- Inherits CloudFormation limits

---

## Key Differences

- **Positioning:** OpenTofu — open-source Terraform fork under the Linux Foundation. AWS CDK — define AWS infrastructure in TypeScript, Python and more.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Deployment:** OpenTofu — CLI. AWS CDK — library / framework in your stack.
- **Pricing:** OpenTofu — free and open source. AWS CDK — free and open source.
- **Signature strength:** OpenTofu — drop-in Terraform compatibility. AWS CDK — high-level constructs.

## Frequently Asked Questions

### Is OpenTofu better than AWS CDK?

It depends on your requirements. OpenTofu is a strong fit for teams wanting Terraform compatibility with an open-source license, while AWS CDK suits AWS developers who want infrastructure in code.

### Is OpenTofu free to use?

Yes, you can start with OpenTofu for free. Pricing model: Free and open source.

### Is AWS CDK free to use?

Yes, you can start with AWS CDK for free. Pricing model: Free and open source.

### Can I self-host OpenTofu or AWS CDK?

OpenTofu can be self-hosted. Deployment options: CLI. AWS CDK runs inside your own stack: library / framework in your stack.

### What are the main drawbacks of OpenTofu and AWS CDK?

OpenTofu: gradual divergence from Terraform; smaller vendor support. AWS CDK: AWS focused; inherits CloudFormation limits.
