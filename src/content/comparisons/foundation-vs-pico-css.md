## Detailed Breakdown

### Foundation

_Responsive front-end framework by ZURB_

**Pros:**

- Flexible grid
- Email framework
- Accessibility focus

**Cons:**

- Development has slowed
- Smaller community

---

### Pico CSS

_Minimal CSS framework for semantic HTML_

**Pros:**

- Styles semantic HTML with few classes
- Lightweight
- Built-in dark mode

**Cons:**

- Limited components
- Less customization

## Key Differences

- **Positioning:** Foundation — responsive front-end framework by ZURB. Pico CSS — minimal CSS framework for semantic HTML.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Pricing:** Foundation — free and open source. Pico CSS — free and open source.
- **Signature strength:** Foundation — flexible grid. Pico CSS — styles semantic HTML with few classes.
