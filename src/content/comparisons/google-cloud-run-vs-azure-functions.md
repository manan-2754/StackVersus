# Google Cloud Run vs Azure Functions: Head-to-Head Comparison

## Quick Verdict

> Google Cloud Run is the better pick for containerized services that should scale to zero. Azure Functions is the better pick for Microsoft and .NET shops.

## Detailed Breakdown

### Google Cloud Run

_Serverless containers and functions on Google Cloud_

**Pros:**

- Run any container image
- Scales to zero
- Supports both functions and services

**Cons:**

- Cold starts
- Google Cloud specific

---

### Azure Functions

_Event-driven serverless compute on Azure_

**Pros:**

- Strong .NET support
- Durable Functions for workflows
- Azure ecosystem integration

**Cons:**

- Azure specific
- Cold starts on consumption plans

---

## Key Differences

- **Positioning:** Google Cloud Run — serverless containers and functions on Google Cloud. Azure Functions — event-driven serverless compute on Azure.
- Both share the same licensing model (proprietary), so the decision comes down to features and workflow fit.
- **Pricing:** Google Cloud Run — free tier, then usage-based pricing. Azure Functions — free tier, then usage-based pricing.
- **Signature strength:** Google Cloud Run — run any container image. Azure Functions — strong .NET support.

### Is Google Cloud Run better than Azure Functions?

It depends on your requirements. Google Cloud Run is a strong fit for containerized services that should scale to zero, while Azure Functions suits Microsoft and .NET shops.

Yes, you can start with Google Cloud Run for free. Pricing model: Free tier, then usage-based pricing.

### Is Azure Functions free to use?

Yes, you can start with Azure Functions for free. Pricing model: Free tier, then usage-based pricing.

### Can I self-host Google Cloud Run or Azure Functions?

Google Cloud Run is offered as a managed service: managed cloud. Azure Functions is offered as a managed service: managed cloud.

### What are the main drawbacks of Google Cloud Run and Azure Functions?

Google Cloud Run: cold starts; Google Cloud specific. Azure Functions: Azure specific; cold starts on consumption plans.
