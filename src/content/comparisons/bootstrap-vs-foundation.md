## Detailed Breakdown

### Bootstrap

_Popular component-based CSS framework_

**Pros:**

- Prebuilt components
- Huge community
- Good documentation

**Cons:**

- Sites can look generic
- Heavier CSS

---

### Foundation

_Responsive front-end framework by ZURB_

**Pros:**

- Flexible grid
- Email framework
- Accessibility focus

**Cons:**

- Development has slowed
- Smaller community

## Key Differences

- **Positioning:** Bootstrap — popular component-based CSS framework. Foundation — responsive front-end framework by ZURB.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Pricing:** Bootstrap — free and open source. Foundation — free and open source.
- **Signature strength:** Bootstrap — prebuilt components. Foundation — flexible grid.
