## Detailed Breakdown

### Next.js

_The React framework by Vercel_

**Pros:**

- Server Components and flexible rendering
- Massive ecosystem
- Built-in image, font and routing optimizations

**Cons:**

- App Router learning curve
- Some features work best on Vercel hosting

---

### Gatsby

_React static site generator with a GraphQL data layer_

**Pros:**

- Large plugin library
- GraphQL layer unifies data sources
- Strong image handling

**Cons:**

- Development has slowed significantly
- Build times grow with site size

---

## Key Differences

- **Positioning:** Next.js — the React framework by Vercel. Gatsby — React static site generator with a GraphQL data layer.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Pricing:** Next.js — free and open source. Gatsby — free and open source.
- **Signature strength:** Next.js — server Components and flexible rendering. Gatsby — large plugin library.
