## Detailed Breakdown

### MikroORM

_TypeScript ORM built on Data Mapper and Unit of Work_

**Pros:**

- Unit of Work and identity map
- Strong TypeScript support
- Multiple databases

**Cons:**

- Smaller community
- More concepts to learn

---

### Kysely

_Type-safe TypeScript SQL query builder_

**Pros:**

- Fully type-safe queries
- Lightweight with no runtime magic
- Works across SQL dialects

**Cons:**

- Not a full ORM
- Types must be kept in sync with your schema
