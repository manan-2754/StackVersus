## Detailed Breakdown

### Nuxt

_Full-stack framework for Vue_

**Pros:**

- File-based routing and auto-imports
- Nitro server engine deploys almost anywhere
- Rich module ecosystem

**Cons:**

- Tied to Vue
- Major upgrades require migration work

---

### Gatsby

_React static site generator with a GraphQL data layer_

**Pros:**

- Large plugin library
- GraphQL layer unifies data sources
- Strong image handling

**Cons:**

- Development has slowed significantly
- Build times grow with site size

---

## Key Differences

- **Positioning:** Nuxt — full-stack framework for Vue. Gatsby — React static site generator with a GraphQL data layer.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Pricing:** Nuxt — free and open source. Gatsby — free and open source.
- **Signature strength:** Nuxt — file-based routing and auto-imports. Gatsby — large plugin library.
