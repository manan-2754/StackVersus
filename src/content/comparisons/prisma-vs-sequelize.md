## Detailed Breakdown

### Prisma

_Type-safe ORM with a schema-first workflow_

**Pros:**

- Declarative schema and migrations
- Excellent autocompletion
- Prisma Studio data browser

**Cons:**

- Abstraction can limit complex SQL
- Heavier than query builders

---

### Sequelize

_Mature promise-based Node.js ORM_

**Pros:**

- Very mature
- Supports many SQL dialects
- Large community

**Cons:**

- TypeScript support is less ergonomic
- Older API design

---

## Key Differences

- **Positioning:** Prisma — type-safe ORM with a schema-first workflow. Sequelize — mature promise-based Node.js ORM.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Pricing:** Prisma — free and open source. Sequelize — free and open source.
- **Signature strength:** Prisma — declarative schema and migrations. Sequelize — very mature.
