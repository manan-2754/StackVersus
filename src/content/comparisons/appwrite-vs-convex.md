## Detailed Breakdown

### Appwrite

_Open-source backend platform for web and mobile_

**Pros:**

- Self-host with Docker
- Auth, databases, storage and functions
- Many client SDKs

**Cons:**

- Smaller community than Firebase
- Cloud offering is younger

---

### Convex

_Reactive backend platform with TypeScript functions_

**Pros:**

- Queries are reactive by default
- Backend logic written in TypeScript
- Transactions built in

**Cons:**

- Proprietary data model and query API
- Less suited to SQL-heavy workloads

## Key Differences

- **Positioning:** Appwrite — open-source backend platform for web and mobile. Convex — reactive backend platform with TypeScript functions.
