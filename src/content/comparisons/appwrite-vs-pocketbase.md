## Detailed Breakdown

### Appwrite

_Open-source backend platform for web and mobile_

**Pros:**

- Self-host with Docker
- Auth, databases, storage and functions
- Many client SDKs

**Cons:**

- Smaller community than Firebase
- Cloud offering is younger

---

### PocketBase

_Open-source backend in a single executable_

**Pros:**

- Single binary with embedded SQLite
- Realtime subscriptions and auth
- Extremely easy to deploy

**Cons:**

- Not built for horizontal scaling
- Pre-1.0 releases may include breaking changes

---

## Key Differences

- **Positioning:** Appwrite — open-source backend platform for web and mobile. PocketBase — open-source backend in a single executable.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Deployment:** Appwrite — self-hosted or managed cloud. PocketBase — self-hosted.
- **Pricing:** Appwrite — free open source; paid managed cloud. PocketBase — free and open source.
- **Signature strength:** Appwrite — self-host with Docker. PocketBase — single binary with embedded SQLite.
