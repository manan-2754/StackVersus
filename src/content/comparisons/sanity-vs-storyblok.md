## Detailed Breakdown

### Sanity

_Composable content platform with a customizable React studio_

**Pros:**

- Highly customizable Sanity Studio
- Real-time collaborative editing
- GROQ query language

**Cons:**

- Content Lake backend is proprietary and hosted
- GROQ is another language to learn

---

### Storyblok

_Headless CMS with a visual editor_

**Pros:**

- Visual editor with live preview
- Component-based content blocks
- Good localization features

**Cons:**

- Proprietary cloud only
- Pricing scales with seats and traffic

---

## Key Differences

- **Positioning:** Sanity — composable content platform with a customizable React studio. Storyblok — headless CMS with a visual editor.
- Licensing differs: Sanity is open-core while Storyblok is proprietary.
- **Pricing:** Sanity — free tier with paid plans. Storyblok — free tier with paid plans.
- **Signature strength:** Sanity — highly customizable Sanity Studio. Storyblok — Visual editor with live preview.
