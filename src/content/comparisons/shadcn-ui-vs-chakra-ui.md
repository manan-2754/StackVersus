## Detailed Breakdown

### Shadcn UI

_Copy-paste components built on Radix and Tailwind_

**Pros:**

- You own the component code
- Accessible Radix primitives
- Tailwind styling

**Cons:**

- You maintain updates yourself
- Assumes Tailwind

---

### Chakra UI

_Accessible React component library_

**Pros:**

- Style props API
- Accessibility built in
- Theming

**Cons:**

- v3 migration effort
- Runtime styling cost

---

## Key Differences

- **Positioning:** Shadcn UI — copy-paste components built on Radix and Tailwind. Chakra UI — accessible React component library.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Pricing:** Shadcn UI — free and open source. Chakra UI — free and open source.
- **Signature strength:** Shadcn UI — you own the component code. Chakra UI — style props API.
