## Detailed Breakdown

### PocketBase

_Open-source backend in a single executable_

**Pros:**

- Single binary with embedded SQLite
- Realtime subscriptions and auth
- Extremely easy to deploy

**Cons:**

- Not built for horizontal scaling
- Pre-1.0 releases may include breaking changes

---

### Convex

_Reactive backend platform with TypeScript functions_

**Pros:**

- Queries are reactive by default
- Backend logic written in TypeScript
- Transactions built in

**Cons:**

- Proprietary data model and query API
- Less suited to SQL-heavy workloads
