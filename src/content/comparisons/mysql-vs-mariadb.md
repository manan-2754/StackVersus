## Detailed Breakdown

### MySQL

_Popular open-source relational database owned by Oracle_

**Pros:**

- Ubiquitous hosting support
- Fast reads
- Mature replication

**Cons:**

- Fewer advanced SQL features than Postgres
- Concerns about Oracle stewardship

---

### MariaDB

_Community-developed fork of MySQL_

**Pros:**

- MySQL compatible
- Additional storage engines
- Open governance

**Cons:**

- Gradually diverging from MySQL
- Fewer managed-service options

---

## Key Differences

- **Positioning:** MySQL — popular open-source relational database owned by Oracle. MariaDB — community-developed fork of MySQL.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Pricing:** MySQL — free and open source. MariaDB — free and open source.
- **Signature strength:** MySQL — ubiquitous hosting support. MariaDB — MySQL compatible.
