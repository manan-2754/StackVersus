## Detailed Breakdown

### TypeORM

_Decorator-based ORM for TypeScript and JavaScript_

**Pros:**

- Active Record and Data Mapper patterns
- Supports many databases
- Popular with NestJS

**Cons:**

- Weaker type safety than newer ORMs
- Uneven maintenance history

---

### Sequelize

_Mature promise-based Node.js ORM_

**Pros:**

- Very mature
- Supports many SQL dialects
- Large community

**Cons:**

- TypeScript support is less ergonomic
- Older API design

---

## Key Differences

- **Positioning:** TypeORM — decorator-based ORM for TypeScript and JavaScript. Sequelize — mature promise-based Node.js ORM.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Pricing:** TypeORM — free and open source. Sequelize — free and open source.
- **Signature strength:** TypeORM — active Record and Data Mapper patterns. Sequelize — very mature.
