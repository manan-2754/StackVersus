## Detailed Breakdown

### Typesense

_Open-source, typo-tolerant search engine_

**Pros:**

- Fast in-memory search
- Simple API
- Managed Typesense Cloud option

**Cons:**

- Index must fit in RAM
- Smaller ecosystem

---

### Apache Solr

_Mature open-source search platform built on Lucene_

**Pros:**

- Very mature
- Powerful faceting
- Apache governance

**Cons:**

- Less developer-friendly than newer engines
- Configuration heavy

---

## Key Differences

- **Positioning:** Typesense — open-source, typo-tolerant search engine. Apache Solr — mature open-source search platform built on Lucene.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Deployment:** Typesense — self-hosted or managed cloud. Apache Solr — self-hosted.
- **Pricing:** Typesense — free open source; paid managed cloud. Apache Solr — free and open source.
- **Signature strength:** Typesense — fast in-memory search. Apache Solr — very mature.
