## Detailed Breakdown

### PocketBase

_Open-source backend in a single executable_

**Pros:**

- Single binary with embedded SQLite
- Realtime subscriptions and auth
- Extremely easy to deploy

**Cons:**

- Not built for horizontal scaling
- Pre-1.0 releases may include breaking changes

---

### Nhost

_Open-source backend with Postgres and GraphQL_

**Pros:**

- Postgres with a Hasura GraphQL API
- Auth and storage included
- Self-hostable

**Cons:**

- GraphQL-centric
- Smaller ecosystem

---

## Key Differences

- **Positioning:** PocketBase — open-source backend in a single executable. Nhost — open-source backend with Postgres and GraphQL.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Deployment:** PocketBase — self-hosted. Nhost — self-hosted or managed cloud.
- **Pricing:** PocketBase — free and open source. Nhost — free open source; paid managed cloud.
- **Signature strength:** PocketBase — single binary with embedded SQLite. Nhost — Postgres with a Hasura GraphQL API.
