## Detailed Breakdown

### PostgreSQL

_Advanced open-source relational database_

**Pros:**

- Rich SQL features and extensions
- Strong standards compliance
- Huge ecosystem

**Cons:**

- Vacuum and tuning knowledge needed
- Horizontal scaling requires extra tooling

---

### MariaDB

_Community-developed fork of MySQL_

**Pros:**

- MySQL compatible
- Additional storage engines
- Open governance

**Cons:**

- Gradually diverging from MySQL
- Fewer managed-service options

---

## Key Differences

- **Positioning:** PostgreSQL — advanced open-source relational database. MariaDB — community-developed fork of MySQL.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Pricing:** PostgreSQL — free and open source. MariaDB — free and open source.
- **Signature strength:** PostgreSQL — rich SQL features and extensions. MariaDB — MySQL compatible.
