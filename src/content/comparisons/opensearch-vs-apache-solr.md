## Detailed Breakdown

### OpenSearch

_Community-driven fork of Elasticsearch_

**Pros:**

- Apache 2.0 license
- Managed option on AWS
- Dashboards and plugins included

**Cons:**

- Feature divergence from Elasticsearch
- Operational complexity

---

### Apache Solr

_Mature open-source search platform built on Lucene_

**Pros:**

- Very mature
- Powerful faceting
- Apache governance

**Cons:**

- Less developer-friendly than newer engines
- Configuration heavy

---

## Key Differences

- **Positioning:** OpenSearch — community-driven fork of Elasticsearch. Apache Solr — mature open-source search platform built on Lucene.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Deployment:** OpenSearch — self-hosted or managed cloud. Apache Solr — self-hosted.
- **Pricing:** OpenSearch — free and open source. Apache Solr — free and open source.
- **Signature strength:** OpenSearch — apache 2.0 license. Apache Solr — very mature.
