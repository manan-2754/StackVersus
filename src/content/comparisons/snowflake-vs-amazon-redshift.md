## Detailed Breakdown

### Snowflake

_Cloud data platform with separated storage and compute_

**Pros:**

- Separation of storage and compute
- Runs on AWS, Azure and Google Cloud
- Secure data sharing marketplace

**Cons:**

- Credit consumption can surprise
- Proprietary platform

---

### Amazon Redshift

_AWS cloud data warehouse_

**Pros:**

- Deep AWS integration
- Serverless option
- Mature SQL warehouse

**Cons:**

- Provisioned clusters need tuning
- AWS only

- **Positioning:** Snowflake — cloud data platform with separated storage and compute. Amazon Redshift — AWS cloud data warehouse.

- **Pricing:** Snowflake — pay-as-you-go usage pricing. Amazon Redshift — pay-as-you-go usage pricing.
- **Signature strength:** Snowflake — separation of storage and compute. Amazon Redshift — deep AWS integration.
