## Detailed Breakdown

### Astro

_Content-focused web framework with islands architecture_

**Pros:**

- Ships zero JavaScript by default
- Mix React, Vue and Svelte components
- Excellent Markdown and content collections

**Cons:**

- Not ideal for highly interactive apps
- Smaller ecosystem than Next.js

---

### Qwik

_Resumable framework for instant-loading web apps_

**Pros:**

- Resumability avoids hydration cost
- Fine-grained lazy loading
- Familiar JSX syntax

**Cons:**

- Small ecosystem
- New mental model to learn

---

## Key Differences

- **Positioning:** Astro — content-focused web framework with islands architecture. Qwik — resumable framework for instant-loading web apps.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Pricing:** Astro — free and open source. Qwik — free and open source.
- **Signature strength:** Astro — ships zero JavaScript by default. Qwik — resumability avoids hydration cost.
