## Detailed Breakdown

### Shadcn UI

_Copy-paste components built on Radix and Tailwind_

**Pros:**

- You own the component code
- Accessible Radix primitives
- Tailwind styling

**Cons:**

- You maintain updates yourself
- Assumes Tailwind

---

### Headless UI

_Unstyled accessible components by Tailwind Labs_

**Pros:**

- Designed for Tailwind
- React and Vue versions
- Accessible

**Cons:**

- Small set of components
- Less flexible than Radix

---

## Key Differences

- **Positioning:** Shadcn UI — copy-paste components built on Radix and Tailwind. Headless UI — unstyled accessible components by Tailwind Labs.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Pricing:** Shadcn UI — free and open source. Headless UI — free and open source.
- **Signature strength:** Shadcn UI — you own the component code. Headless UI — designed for Tailwind.
