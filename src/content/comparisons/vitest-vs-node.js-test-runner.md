## Detailed Breakdown

### Vitest

_Vite-native unit test framework_

**Pros:**

- Very fast watch mode
- Jest-compatible API
- Native ESM and TypeScript support

**Cons:**

- Most benefit when you already use Vite
- Younger ecosystem than Jest

---

### Node.js Test Runner

_Test runner built into Node.js (node:test)_

**Pros:**

- Nothing extra to install
- Built-in mocking and coverage
- Stable since Node.js 20

**Cons:**

- Fewer features than Jest or Vitest
- Smaller ecosystem of reporters and plugins

---

## Key Differences

- **Positioning:** Vitest — Vite-native unit test framework. Node.js Test Runner — test runner built into Node.js (node:test).
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Deployment:** Vitest — library / framework in your stack. Node.js Test Runner — built into the Node.js runtime.
- **Pricing:** Vitest — free and open source. Node.js Test Runner — free and open source.
- **Signature strength:** Vitest — very fast watch mode. Node.js Test Runner — nothing extra to install.
