# AWS CDK vs Crossplane: Head-to-Head Comparison

## Quick Verdict

> AWS CDK is the better pick for AWS developers who want infrastructure in code. Crossplane is the better pick for platform teams building internal platforms on Kubernetes.

## Detailed Breakdown

### AWS CDK

_Define AWS infrastructure in TypeScript, Python and more_

**Pros:**

- High-level constructs
- Real programming languages
- Synthesizes to CloudFormation

**Cons:**

- AWS focused
- Inherits CloudFormation limits

---

### Crossplane

_Kubernetes-native control plane for cloud infrastructure_

**Pros:**

- Manage infrastructure through Kubernetes APIs
- Compositions for platform abstractions
- Continuous reconciliation

**Cons:**

- Requires Kubernetes expertise
- Steeper learning curve

---

## Key Differences

- **Positioning:** AWS CDK — define AWS infrastructure in TypeScript, Python and more. Crossplane — Kubernetes-native control plane for cloud infrastructure.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Deployment:** AWS CDK — library / framework in your stack. Crossplane — runs in your Kubernetes cluster.
- **Pricing:** AWS CDK — free and open source. Crossplane — free and open source.
- **Signature strength:** AWS CDK — high-level constructs. Crossplane — manage infrastructure through Kubernetes APIs.

## Frequently Asked Questions

### Is AWS CDK better than Crossplane?

It depends on your requirements. AWS CDK is a strong fit for AWS developers who want infrastructure in code, while Crossplane suits platform teams building internal platforms on Kubernetes.

### Is AWS CDK free to use?

Yes, you can start with AWS CDK for free. Pricing model: Free and open source.

### Is Crossplane free to use?

Yes, you can start with Crossplane for free. Pricing model: Free and open source.

### Can I self-host AWS CDK or Crossplane?

AWS CDK runs inside your own stack: library / framework in your stack. Crossplane can be self-hosted. Deployment options: runs in your Kubernetes cluster.

### What are the main drawbacks of AWS CDK and Crossplane?

AWS CDK: AWS focused; inherits CloudFormation limits. Crossplane: requires Kubernetes expertise; steeper learning curve.
