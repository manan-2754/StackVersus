# Terraform vs AWS CDK: Head-to-Head Comparison

## Quick Verdict

> Terraform is the better pick for multi-cloud infrastructure with the largest provider ecosystem. AWS CDK is the better pick for AWS developers who want infrastructure in code.

---

| Feature           | Terraform                                                      | AWS CDK                                        |
| :---------------- | :------------------------------------------------------------- | :--------------------------------------------- |

| **Pricing**       | Free CLI; paid HCP Terraform                                   | Free and open source                           |

## Detailed Breakdown

### Terraform

_Infrastructure as code with HCL by HashiCorp_

**Pros:**

- Huge provider ecosystem
- Declarative HCL
- Widely adopted

**Cons:**

- Moved to the BSL license in 2023
- State management complexity

---

### AWS CDK

_Define AWS infrastructure in TypeScript, Python and more_

**Pros:**

- High-level constructs
- Real programming languages
- Synthesizes to CloudFormation

**Cons:**

- AWS focused
- Inherits CloudFormation limits

---

## Key Differences

- **Positioning:** Terraform — infrastructure as code with HCL by HashiCorp. AWS CDK — define AWS infrastructure in TypeScript, Python and more.
- Licensing differs: Terraform is source-available while AWS CDK is open source.
- **Deployment:** Terraform — CLI with optional HCP Terraform cloud. AWS CDK — library / framework in your stack.
- **Pricing:** Terraform — free CLI; paid HCP Terraform. AWS CDK — free and open source.
- **Signature strength:** Terraform — huge provider ecosystem. AWS CDK — high-level constructs.

## Frequently Asked Questions

### Is Terraform better than AWS CDK?

It depends on your requirements. Terraform is a strong fit for multi-cloud infrastructure with the largest provider ecosystem, while AWS CDK suits AWS developers who want infrastructure in code.

### Is Terraform free to use?

Yes, you can start with Terraform for free. Pricing model: Free CLI; paid HCP Terraform.

### Is AWS CDK free to use?

Yes, you can start with AWS CDK for free. Pricing model: Free and open source.

### Can I self-host Terraform or AWS CDK?

Terraform can be self-hosted. Deployment options: CLI with optional HCP Terraform cloud. AWS CDK runs inside your own stack: library / framework in your stack.

### What are the main drawbacks of Terraform and AWS CDK?

Terraform: moved to the BSL license in 2023; state management complexity. AWS CDK: AWS focused; inherits CloudFormation limits.
