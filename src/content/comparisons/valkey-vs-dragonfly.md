## Detailed Breakdown

### Valkey

_Open-source Redis fork backed by the Linux Foundation_

**Pros:**

- Redis-compatible
- BSD license
- Backed by major cloud vendors

**Cons:**

- Younger project
- Feature divergence from Redis over time

---

### Dragonfly

_Multithreaded Redis- and Memcached-compatible store_

**Pros:**

- Multithreaded architecture
- Redis and Memcached API compatibility
- Efficient memory use

**Cons:**

- BSL license
- Not every Redis command is supported

## Key Differences

- **Positioning:** Valkey — open-source Redis fork backed by the Linux Foundation. Dragonfly — multithreaded Redis- and Memcached-compatible store.
