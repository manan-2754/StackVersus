# SQLite vs Apache Cassandra: Head-to-Head Comparison

## Quick Verdict

> SQLite is the better pick for embedded, mobile and single-node apps. Apache Cassandra is the better pick for write-heavy workloads needing high availability across regions.

## Detailed Breakdown

### SQLite

_Embedded, serverless SQL database engine_

**Pros:**

- Zero configuration
- Single-file database
- Extremely reliable and well tested

**Cons:**

- Limited write concurrency
- No built-in network access

---

### Apache Cassandra

_Distributed wide-column NoSQL database_

**Pros:**

- Linear horizontal scaling
- No single point of failure
- Multi-datacenter replication

**Cons:**

- Query patterns must be designed upfront
- Operationally demanding

---

## Key Differences

- **Positioning:** SQLite — embedded, serverless SQL database engine. Apache Cassandra — distributed wide-column NoSQL database.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Deployment:** SQLite — embedded in your application. Apache Cassandra — self-hosted or managed cloud.
- **Pricing:** SQLite — free, public domain. Apache Cassandra — free and open source.
- **Signature strength:** SQLite — zero configuration. Apache Cassandra — linear horizontal scaling.
