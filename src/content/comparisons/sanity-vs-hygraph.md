## Detailed Breakdown

### Sanity

_Composable content platform with a customizable React studio_

**Pros:**

- Highly customizable Sanity Studio
- Real-time collaborative editing
- GROQ query language

**Cons:**

- Content Lake backend is proprietary and hosted
- GROQ is another language to learn

---

### Hygraph

_GraphQL-native headless CMS_

**Pros:**

- Native GraphQL API including mutations
- Content federation from external sources
- Strong schema modeling

**Cons:**

- GraphQL-centric approach
- Lower-tier limits can be restrictive

---

## Key Differences

- **Positioning:** Sanity — composable content platform with a customizable React studio. Hygraph — GraphQL-native headless CMS.
- Licensing differs: Sanity is open-core while Hygraph is proprietary.
- **Pricing:** Sanity — free tier with paid plans. Hygraph — free tier with paid plans.
- **Signature strength:** Sanity — highly customizable Sanity Studio. Hygraph — native GraphQL API including mutations.
