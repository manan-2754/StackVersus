## Detailed Breakdown

### Payload CMS

_TypeScript-first headless CMS and app framework_

**Pros:**

- Configuration written entirely in TypeScript
- Installs directly into a Next.js app
- Fine-grained access control

**Cons:**

- Changes require developer involvement
- Smaller ecosystem than older CMSs

---

### Hygraph

_GraphQL-native headless CMS_

**Pros:**

- Native GraphQL API including mutations
- Content federation from external sources
- Strong schema modeling

**Cons:**

- GraphQL-centric approach
- Lower-tier limits can be restrictive

---

## Key Differences

- **Positioning:** Payload CMS — TypeScript-first headless CMS and app framework. Hygraph — GraphQL-native headless CMS.
- Licensing differs: Payload CMS is open source while Hygraph is proprietary.
- **Deployment:** Payload CMS — self-hosted or managed cloud. Hygraph — managed cloud.
- **Pricing:** Payload CMS — free open source; paid managed cloud. Hygraph — free tier with paid plans.
- **Signature strength:** Payload CMS — configuration written entirely in TypeScript. Hygraph — native GraphQL API including mutations.
