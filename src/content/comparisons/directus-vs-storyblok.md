## Detailed Breakdown

### Directus

_Data platform that adds an API and admin app to any SQL database_

**Pros:**

- Works on top of existing SQL schemas
- Instant REST and GraphQL APIs
- No-code admin app

**Cons:**

- BSL license requires a paid license for larger organizations
- Admin customization has a learning curve

---

### Storyblok

_Headless CMS with a visual editor_

**Pros:**

- Visual editor with live preview
- Component-based content blocks
- Good localization features

**Cons:**

- Proprietary cloud only
- Pricing scales with seats and traffic

---

## Key Differences

- **Positioning:** Directus — data platform that adds an API and admin app to any SQL database. Storyblok — headless CMS with a visual editor.
- Licensing differs: Directus is source-available while Storyblok is proprietary.
- **Deployment:** Directus — self-hosted or managed cloud. Storyblok — managed cloud.
- **Pricing:** Directus — free open source; paid managed cloud. Storyblok — free tier with paid plans.
- **Signature strength:** Directus — works on top of existing SQL schemas. Storyblok — Visual editor with live preview.
