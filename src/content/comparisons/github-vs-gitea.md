## Detailed Breakdown

### GitHub

_The largest code hosting platform_

**Pros:**

- Largest developer community
- Actions, Codespaces and Copilot
- Excellent pull request workflow

**Cons:**

- Advanced security costs extra
- Self-hosting requires Enterprise Server

---

### Gitea

_Lightweight self-hosted Git service_

**Pros:**

- Very lightweight
- Actions-compatible CI
- Easy to run

**Cons:**

- Smaller ecosystem
- You manage hosting

---

## Key Differences

- **Positioning:** GitHub — the largest code hosting platform. Gitea — lightweight self-hosted Git service.
- Licensing differs: GitHub is proprietary while Gitea is open source.
- **Deployment:** GitHub — managed cloud or Enterprise Server. Gitea — self-hosted.
- **Pricing:** GitHub — free tier with paid plans. Gitea — free and open source.
- **Signature strength:** GitHub — largest developer community. Gitea — very lightweight.
