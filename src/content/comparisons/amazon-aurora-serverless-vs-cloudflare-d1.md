# Amazon Aurora Serverless vs Cloudflare D1: Head-to-Head Comparison

## Quick Verdict

> Amazon Aurora Serverless is the better pick for AWS workloads with variable traffic. Cloudflare D1 is the better pick for Cloudflare Workers apps that need a SQL database.

## Detailed Breakdown

### Amazon Aurora Serverless

_Auto-scaling MySQL and PostgreSQL on AWS_

**Pros:**

- Automatic capacity scaling
- MySQL and Postgres compatibility
- Deep AWS integration

**Cons:**

- AWS only
- Pricing can be complex to estimate

---

### Cloudflare D1

_Serverless SQLite database on Cloudflare_

**Pros:**

- Native Workers bindings
- Free tier included
- Global read replication

**Cons:**

- Per-database size limits
- Tied to the Cloudflare platform

---

## Key Differences

- **Positioning:** Amazon Aurora Serverless — auto-scaling MySQL and PostgreSQL on AWS. Cloudflare D1 — serverless SQLite database on Cloudflare.
- Both share the same licensing model (proprietary), so the decision comes down to features and workflow fit.
- Cloudflare D1 can be started for free, while Amazon Aurora Serverless requires a paid plan. Amazon Aurora Serverless pricing: pay-as-you-go usage pricing.
- **Signature strength:** Amazon Aurora Serverless — automatic capacity scaling. Cloudflare D1 — native Workers bindings.

## Frequently Asked Questions

### Is Amazon Aurora Serverless better than Cloudflare D1?

It depends on your requirements. Amazon Aurora Serverless is a strong fit for AWS workloads with variable traffic, while Cloudflare D1 suits Cloudflare Workers apps that need a SQL database.

### Is Amazon Aurora Serverless free to use?

Amazon Aurora Serverless does not have a permanent free plan. Pricing model: Pay-as-you-go usage pricing.

### Is Cloudflare D1 free to use?

Yes, you can start with Cloudflare D1 for free. Pricing model: Free tier, then usage-based pricing.

### Can I self-host Amazon Aurora Serverless or Cloudflare D1?

Amazon Aurora Serverless is offered as a managed service: managed cloud. Cloudflare D1 is offered as a managed service: managed cloud.

### What are the main drawbacks of Amazon Aurora Serverless and Cloudflare D1?

Amazon Aurora Serverless: AWS only; pricing can be complex to estimate. Cloudflare D1: per-database size limits; tied to the Cloudflare platform.
