## Detailed Breakdown

### Astro

_Content-focused web framework with islands architecture_

**Pros:**

- Ships zero JavaScript by default
- Mix React, Vue and Svelte components
- Excellent Markdown and content collections

**Cons:**

- Not ideal for highly interactive apps
- Smaller ecosystem than Next.js

---

### Nuxt

_Full-stack framework for Vue_

**Pros:**

- File-based routing and auto-imports
- Nitro server engine deploys almost anywhere
- Rich module ecosystem

**Cons:**

- Tied to Vue
- Major upgrades require migration work

---

## Key Differences

- **Positioning:** Astro — content-focused web framework with islands architecture. Nuxt — full-stack framework for Vue.
- Both share the same licensing model (open source), so the decision comes down to features and workflow fit.
- **Pricing:** Astro — free and open source. Nuxt — free and open source.
- **Signature strength:** Astro — ships zero JavaScript by default. Nuxt — file-based routing and auto-imports.
