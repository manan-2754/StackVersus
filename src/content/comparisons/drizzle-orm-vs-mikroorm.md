## Detailed Breakdown

### Drizzle ORM

_Lightweight, SQL-like TypeScript ORM_

**Pros:**

- SQL-like API
- Lightweight and serverless friendly
- No separate code generation step

**Cons:**

- Younger ecosystem
- Fewer high-level abstractions

---

### MikroORM

_TypeScript ORM built on Data Mapper and Unit of Work_

**Pros:**

- Unit of Work and identity map
- Strong TypeScript support
- Multiple databases

**Cons:**

- Smaller community
- More concepts to learn
