## Detailed Breakdown

### Ollama

_Run large language models locally_

**Pros:**

- One-command model downloads
- OpenAI-compatible API
- Cross-platform

**Cons:**

- Not built for high-throughput serving
- Fewer tuning options

---

### llama.cpp

_LLM inference in C/C++_

**Pros:**

- Runs on CPUs and Apple Silicon
- GGUF quantization
- Minimal dependencies

**Cons:**

- Lower-level tooling
- Manual configuration
