## Detailed Breakdown

### MySQL

_Popular open-source relational database owned by Oracle_

**Pros:**

- Ubiquitous hosting support
- Fast reads
- Mature replication

**Cons:**

- Fewer advanced SQL features than Postgres
- Concerns about Oracle stewardship

---

### MongoDB

_Document database with flexible schemas_

**Pros:**

- Flexible JSON-like documents
- Atlas managed service
- Built-in horizontal sharding

**Cons:**

- SSPL license
- Joins are less natural than in SQL

---

## Key Differences

- **Positioning:** MySQL — popular open-source relational database owned by Oracle. MongoDB — document database with flexible schemas.
- Licensing differs: MySQL is open source while MongoDB is source-available.
- **Pricing:** MySQL — free and open source. MongoDB — free community server; paid Atlas cloud.
- **Signature strength:** MySQL — ubiquitous hosting support. MongoDB — flexible JSON-like documents.
