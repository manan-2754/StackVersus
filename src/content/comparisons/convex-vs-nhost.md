## Detailed Breakdown

### Convex

_Reactive backend platform with TypeScript functions_

**Pros:**

- Queries are reactive by default
- Backend logic written in TypeScript
- Transactions built in

**Cons:**

- Proprietary data model and query API
- Less suited to SQL-heavy workloads

---

### Nhost

_Open-source backend with Postgres and GraphQL_

**Pros:**

- Postgres with a Hasura GraphQL API
- Auth and storage included
- Self-hostable

**Cons:**

- GraphQL-centric
- Smaller ecosystem

## Key Differences

- **Positioning:** Convex — reactive backend platform with TypeScript functions. Nhost — open-source backend with Postgres and GraphQL.
