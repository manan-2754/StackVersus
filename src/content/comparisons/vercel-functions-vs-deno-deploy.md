## Detailed Breakdown

### Vercel Functions

_Serverless functions on Vercel_

**Pros:**

- Zero-config with Next.js
- Fluid compute improves concurrency
- Deployed alongside your frontend

**Cons:**

- Tied to Vercel
- Usage costs at scale

---

### Deno Deploy

_Serverless JavaScript hosting by the Deno team_

**Pros:**

- Native TypeScript
- Fast global deploys
- Web-standard APIs

**Cons:**

- Smaller ecosystem
- Fewer regions than large clouds

---

## Key Differences

- **Positioning:** Vercel Functions — serverless functions on Vercel. Deno Deploy — serverless JavaScript hosting by the Deno team.
- Both share the same licensing model (proprietary), so the decision comes down to features and workflow fit.
- **Pricing:** Vercel Functions — free tier, then usage-based pricing. Deno Deploy — free tier with paid plans.
- **Signature strength:** Vercel Functions — zero-config with Next.js. Deno Deploy — native TypeScript.
